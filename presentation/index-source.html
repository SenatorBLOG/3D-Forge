How it works

One pipeline: prompt → image → 3D → edit

The user always sees — and approves the picture — before spending a 3D generation. Verify on the image, then commit to the model.
01 · USER

Prompt

Type what you want in plain language.

▶
02 · GEMINI

Reference image

A picture is generated from the prompt.

✓ preview & verify before 3D
▶
03 · TRIPO

3D model

The approved image becomes a real GLB mesh.

▶
04 · VIEWER

Model in browser

Orbit, inspect, and keep every version.

Re-imagine · multi-view

Refine the whole model

Snapshot 4 sides → Gemini → verify new image → Tripo → fresh model.
Texture

Recolor & retexture

Restyle the same mesh — e.g. glossy red or clean white/blue — no re-modeling.
Segment · part edit

Change one part only

Tripo splits into parts → pick one → 4-view → Gemini → verify → rebuild & stitch back.
Honest note: a rebuilt part is a new mesh, so re-inserting it can need a little alignment — an open research nuance we show live.
